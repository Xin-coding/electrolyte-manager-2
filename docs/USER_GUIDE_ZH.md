# Electrolyte Manager 2.0 使用说明

当前版本：2.0.2。正式设置、泵测试、装液额度和历史时间范围增加字段输入保护；保留 2.0.1 的推力编码、计量稳定性和故障原因显示修复。

## 输入与修改设置

数值字段离开焦点或点击“应用设置”时检查。错误字段显示红框，字段下方写明原因；不会在输入到一半时弹窗打断。修改正确后，离开字段即可清除提示。界面切换语言时，错误原因同步切换；数据管理页始终使用英文。

允许首尾空格、英文小数点和科学计数法，如 `0.100`、`1e-1`。不要把单位输入字段，不接受逗号、中文逗号、多个小数点、NaN、无穷值或混合文字。过大、过小而无法表示的数值不会被静默转换为有效参数。整数形式推力 `50.0` 可用；`50.5` 不会截断。

检查包括：正体积和正速率、20–100 整数推力、非负混合时间、0.5–3600 秒 pH 采样间隔、泵协议体积精度与注射时间、当前注射器容量、正容差、下侧报警小于上侧报警，以及目标 ± 容差严格位于报警边界内。STOP 测试的泵端上限必须大于软件停止量；错误 STOP 上限不影响参数有效的普通定量测试。

输入只是草稿。错误草稿不会发送设置请求，不会更换当前有效版本或已有待生效版本，不会停止实验、重置混合倒计时或清除已用量。修正后点击“应用设置”，仍按原来的版本生效规则执行。点击“启用 / 继续反馈”使用当前有效设置，不会自动应用草稿。

目标可留空，以初始稳定值为目标。尚未配置完整的控制参数可以保存为预设、开始数据记录，但不能启用反馈；反馈运行期间不能应用缺失必要控制参数的配置。记录性实验信息仍可自由填写、留空，不作为启动或停泵判据。

装液额度使用独立的“更改额度”按钮。剩余额度不足完整一针时不启动下一针，仍可记录数据和保存其他有效设置。界面会显示当前有效额度、已用量、剩余量及不足提示。无效配置文件在加载时拒绝，不替换当前表单或运行设置。

## 文件位置

本机根目录：`C:\Users\Xin\Desktop\Electrolyte-Manager-2.0`。

- `app\ElectrolyteManager.exe`：桌面程序，必须与 `_internal` 文件夹一起保留。
- `source`：独立重写的源码、自动测试、构建工具与文档。
- `data`：实验 SQLite、配置、装液账本、设备绑定、测试记录和诊断日志，只保存在本机。
- `exports`：导出文件、图表和本次验收报告。

## 连接与首次使用

在设备连接页自动识别，或手动选择 COM 端口连接。每个端口只允许一个通信线程，已被本程序使用的端口不可再绑定给另一设备。重连优先匹配 USB 设备身份；身份缺失或不唯一时不自动换到其他端口。USB 转串口适配器的身份不是仪器本体序列号，移动适配器到另一台同型号仪器时应人工核实。

PC8500 请在仪器上设为每分钟上传。软件不发送未经验证的采样间隔设置命令。仪器的身份查询仅用于连接握手，运行中不反复发送会干扰 PC-Link 的身份查询。USB 断开由串口读写异常检测；安静的取样间隔显示最近一次接收时间并等待新记录，不作为结束实验的理由。

记录可以在参数未完成或设备暂未连接时开始。启用反馈需要明确设置单次量、流速、推力、混合时间、装液额度、容差和上下报警边界。实验说明字段可空，不参与控制。

目标留空时，从开始记录后收集稳定的原始值：pH 连续 5 点极差不超过 0.05；电导率连续 3 点极差不超过均值的 1%。均值一旦确定便固定。未稳定时可以继续记录或手动填写目标。

## 泵测试、额度与换液

泵测试不要求连接 pH 或电导率，也不要求开始实验。定量测试与软件 STOP 测试各自使用测试页面参数，不改变正式实验剂量、速率等设置。实际消耗计入同一次装液已用量。

软件 STOP 测试的泵端有限量必须大于软件停止量。软件监测泵计数到达停止量后发出 STOP，并保存停止前运行状态、指令回执和停止确认。轮询和机械响应有延迟，实际量可能略超过软件停止量；此测试用来验证软件能在泵端限量之前停止，精确定量使用泵端有限量模式。

正式每针均先写体积，再刷新流速并核对泵内部注射时间。泵端有限量停止与软件监督并行。软件监督保留短暂启动响应余量；不能用 START 回执时刻直接等同于机械运动开始。

“更改额度”改变本次装液总可用额度，不清除已用量；注射或混合中修改会等待本周期完成。“已换液，重置额度”仅在确认停泵后使用，重置当前装液计量，整场实验累计量不清零。额度不足完整一针时暂停新加液，继续记录。

仪器只提供容量、有效面积、推力等信息，软件不伪造注射器型号或校准历史。首次启用及注射器配置变化后显示确认框。软件不执行校准。

## 暂停与异常

普通目标变化不打断正在进行的针；报警、手动暂停、急停、推力故障和持续存储失败可提前停止。报警中断的剩余体积不会补做。信号恢复后，只有报警暂停能够自动恢复；手动暂停、急停和泵故障需要使用“启用 / 继续反馈”。

控制传感器断线时完成已下发有限针，然后等待新的有效读数；非控制传感器断线不影响反馈。泵通信中断时不发送新针并尝试 STOP。重连核实身份、配置、停止和计量后才恢复。无法核实的针保留实际原因，可在已确认停泵后输入经人工核实的实际量；未知量不会当作零。

程序退出或崩溃后不续跑旧反馈。未正常结束的数据库在下一次启动时标记异常结束；新实验重新记录。崩溃前未结算的注射保留在本地装液账本，必须核实或实际换液后重新设置，不能悄悄清零。

## 数据与 OH⁻ 显示

图表默认显示 EMA 平滑，系数 0.5；原始值始终保存。报警判断使用原始值。断线重连和切换控制信号时重新初始化平滑。

OH⁻ 显示算法：`1000 × 10^(平滑pH − pKw(T)) mmol/L`。先平滑 pH，再用对应测量温度换算。pKw 表采用 IAPWS 常压纯水参考值，以 1 °C 间隔线性插值；仅支持 0–99 °C。无有效温度不计算。它是基于稀溶液近似的估算，尤其在浓电解液中不等于直接测得的真实浓度；反馈仍使用 pH。

数据管理支持多场对比、时间范围、原始/处理值、CSV、JSON/JSONL、PNG/SVG 和完整 `.em2zip`。查看与导出不会连接或控制泵。事件采用 JSONL 逐行格式，避免长期实验导出时一次性占用大量内存。

详细验收范围与未完成项见 `VALIDATION.md`。本次缓冲溶液测试不代表已验证电解过程中的化学闭环效果。
